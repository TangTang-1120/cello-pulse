# Cello Pulse / Cello Studio

大提琴练习伴侣：跟奏小游戏 · 调音器 · 节拍器 · 把位识别。

## 功能

- **跟奏 · 节奏跟奏**：四弦轨道下落音块
- **跟奏 · 点弦识谱**：音阶 / 练习曲 / 乐曲，看谱点 IV–I 弦（小白向，不用麦克风）
- **调音器**：C / G / D / A 空弦，麦克风音高检测
- **节拍器**：可调 BPM
- **把位**：实时识别指位并高亮指板图

## 本地运行

```bash
npm install
npm run dev
```
