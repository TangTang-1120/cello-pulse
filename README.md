# Cello Pulse / Cello Studio

大提琴练习伴侣：调音器 · 节拍器 · 把位识别。

## 功能

- **调音器**：C / G / D / A 空弦，麦克风音高检测
- **节拍器**：可调 BPM，听觉节拍
- **把位**：实时识别指位并高亮指板图

## 本地运行

```bash
npm install
npm run dev
```
