Cello Studio · 微信小程序上传包

用微信开发者工具打开本文件夹（选择「小程序」）。
project.config.json 里 appid 现为 touristappid，上传前改成你的小程序 AppID。

上传步骤
1. 打开微信开发者工具 → 导入项目 → 选本文件夹
2. 填写 AppID
3. 右上角「上传」，填版本号 1.0.0
4. 登录微信公众平台 → 版本管理 → 提交审核

说明
完整调音/节拍/把位/内购在 App Store 版。小程序为品牌入口。
同目录 H5 静态资源可放到已备案 https 域名后，再在页面里用 web-view 打开（需企业主体并配置业务域名）。
